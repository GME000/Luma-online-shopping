# Luma Shopping Cart

Responsive React shopping cart application built for the Module 20 assignment.

## Features

- Responsive product catalog with category filters
- Product cards with image, category, color, title, and price
- Product quick-view details modal
- Centralized cart state using React Context and hooks
- Add products, increase/decrease quantities, and remove items
- Live bag item count and subtotal
- Responsive shopping bag drawer with empty and populated states

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
